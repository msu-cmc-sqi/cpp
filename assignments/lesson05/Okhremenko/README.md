# Lesson 05 — Локальный чат с памятью на C++17

## Описание

Консольное приложение на C++17 для общения с локальной языковой моделью через HTTP API `llama-server`.

Программа умеет:
- принимать несколько вопросов подряд;
- хранить историю диалога в `std::vector<Message>`;
- формировать JSON-запросы через `nlohmann::json`;
- отправлять HTTP-запросы через `libcurl`;
- подсчитывать входные токены перед генерацией;
- удалять самые старые завершённые пары сообщений при переполнении контекста;
- отказывать в обработке одного слишком длинного сообщения;
- выводить статистику использования токенов;
- очищать историю командой `/reset` и завершаться командой `/exit`.

## Настройки

- Размер контекста: **1024 токена**
- Максимальная длина ответа: **64 токена**
- Количество потоков CPU: **2**
- Одновременных запросов: **1**
- Адрес сервера по умолчанию: `http://127.0.0.1:8080`
- Имя модели по умолчанию: `local-model`

Перед генерацией выполняется проверка:

`input_tokens + max_tokens <= 1024`

Если история слишком велика, программа удаляет старейшую завершённую пару `user`–`assistant` и повторяет подсчёт токенов.

## Сборка на Windows

Требуются Visual Studio 2022 с поддержкой C++, CMake и vcpkg с установленной библиотекой `curl:x64-windows`.

Из папки проекта выполните в Developer PowerShell for VS 2022:

```powershell
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 -DCMAKE_TOOLCHAIN_FILE="C:/Users/Public/cpp-tools/vcpkg/scripts/buildsystems/vcpkg.cmake"

cmake --build build --config Debug
```

Если vcpkg установлен в другой папке, необходимо изменить путь к `vcpkg.cmake`.

## Запуск сервера

Из каталога `llama.cpp`:

```powershell
.\build\bin\Release\llama-server.exe -m models/qwen2.5-0.5b-instruct-q4_k_m.gguf --alias local-model -c 1024 -ngl 0 -t 2 -np 1 --host 127.0.0.1 --port 8080
```

Терминал с сервером должен оставаться открытым.

Проверка доступности сервера:

```powershell
curl.exe http://127.0.0.1:8080/health
```

Ожидаемый результат: `{"status":"ok"}`.

## Запуск клиента

Из каталога проекта:

```powershell
.\build\Debug\local_chat.exe
```

Также можно явно задать адрес сервера и имя модели:

```powershell
.\build\Debug\local_chat.exe "http://127.0.0.1:8080" "local-model"
```

Команды чата:
- `/reset` — очистка истории;
- `/exit` — завершение работы.

## Примеры работы

### Пример 1. Диалог с памятью

**Вопрос 1:** `привет! как дела?`

**Ответ модели:** `Привет! Я рад пообщаться с вами! Как я могу помочь вам сегодня?`

Статистика: вход — 37, ответ — 23, всего — 60 токенов.

**Вопрос 2:** `О чём я тебя только что спросил?`

**Ответ модели:** `Я спрашиваю о тебе, как дела?`

Статистика: вход — 80, ответ — 13, всего — 93 токена.

**Оценка:** входные токены увеличились, подсчет токенов работает, контекст держится. 
### Пример 2. Переполнение истории

Для теста было отправлено шесть длинных запросов с повторением фразы `Tell me one short C++ fact.`.

Фрагмент фактического вывода:

```text
Вход: 350, ответ: 64, всего: 414 / 1024
Вход: 745, ответ: 64, всего: 809 / 1024

Удалено старых пар: 1
Вход: 745, ответ: 64, всего: 809 / 1024
```

Сообщение `Удалено старых пар: 1` появилось четыре раза.

**Оценка:** программа корректно обнаруживает, что история не помещается в установленный бюджет, удаляет старую завершённую пару и продолжает генерацию. Входные токены после сокращения истории остаются в пределах допустимого значения.

### Пример 3. Слишком длинный запрос

В программу отправлен одиночный запрос, состоящий из 140 повторений `Tell me one short C++ fact.`.

Фактическое сообщение:

```text
Сообщение слишком длинное. Сократите его.
```

После этого отправлен короткий вопрос `Hello!`.

**Ответ модели:** `Hello! How can I assist you today? Please let me know if you have any specific questions or if you need any information about any topic.`

Статистика: вход — 31, ответ — 30, всего — 61 токен.

**Оценка:** слишком длинный запрос не был отправлен на генерацию. Программа продолжила работу и успешно обработала следующий короткий вопрос.

## Обработка ошибок

Программа проверяет доступность сервера, сетевые ошибки и тайм-ауты, HTTP-статус, корректность JSON и обязательные поля ответа.

Тайм-аут подключения — 5 секунд, обычного запроса — 180 секунд, запроса подсчёта токенов — 10 секунд.

При ошибке программа выводит сообщение и завершает работу с ненулевым кодом. При ошибке генерации неподтверждённая реплика пользователя удаляется из истории.

## Пример конфигурации

Файл `config.example.json` содержит пример параметров локального сервера и ограничений контекста. Он предназначен для справки и не загружается программой автоматически.

Адрес сервера и имя модели задаются аргументами командной строки:

```powershell
.\build\Debug\local_chat.exe "http://127.0.0.1:8080" "local-model"
```

По умолчанию используются эти же значения. Ограничения `context_size = 1024` и `max_tokens = 64` заданы в `include/chat_types.hpp`. Размер контекста сервера необходимо отдельно установить параметром `-c 1024`.
