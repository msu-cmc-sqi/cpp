# Урок 3. Современный C++17 и функции как объекты

## Цель

Освоить средства C++17, которые пригодятся при работе с конфигурацией, обработке ответов модели и регистрации инструментов приложения.

## `std::optional`

`std::optional<T>` используется, когда значение может отсутствовать:

```cpp
std::optional<int> parse_context_size(std::string_view text);
```

Это лучше, чем специальные значения вроде `-1`, если `-1` может быть допустимым результатом или не объясняет причину ошибки.

## `std::variant` и `std::visit`

`std::variant` хранит одно значение из заранее известного набора типов:

```cpp
using ConfigValue =
    std::variant<std::monostate, int, double, bool, std::string>;
```

Для обработки значения удобно использовать `std::visit` вместе с `if constexpr`.

## Лямбды и `std::function`

Лямбда-выражение можно сохранить и вызвать позднее:

```cpp
using Tool = std::function<std::string(std::string_view)>;

Tool length = [](std::string_view text) {
    return std::to_string(text.size());
};
```

На этом принципе строятся обработчики событий, команды CLI и простейший реестр инструментов для AI-приложения.

## Стандартные алгоритмы

Для поиска, фильтрации и агрегации следует уметь применять:

- `std::count_if`;
- `std::max_element`;
- `std::transform`;
- `std::accumulate`;
- `std::find_if`.

Алгоритмы не всегда короче обычного цикла, но часто точнее выражают намерение программы.

## Использование ИИ

Использование чата с ИИ разрешено. В запрос полезно включать условие, свой вариант кода, сообщение компилятора или номер не прошедшего теста. При проверке предложенного решения обратите внимание на:

- точный тип возвращаемого значения;
- обработку всех альтернатив `variant`;
- полный разбор строки, а не только её начала;
- переполнение чисел;
- пустые контейнеры;
- время жизни объектов, захваченных лямбдой;
- поведение при неизвестном имени инструмента.

Полезно самостоятельно добавить тест, на котором первое предложенное ИИ решение работает неправильно, и исправить найденную проблему.
